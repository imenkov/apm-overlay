# Security Policy

## Supported versions

Security fixes are provided for the default branch and the latest published
release, when releases are available.

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's private
vulnerability reporting for this repository, if enabled. If private reporting is
not available, open a minimal public issue that asks for a private contact path
without including exploit details, sensitive logs, or proof-of-concept payloads.

Please include:

- The affected version or commit.
- A clear description of the issue and impact.
- Reproduction steps, if safe to share privately.
- Any relevant environment details.

Do not disclose vulnerabilities publicly until there has been a reasonable
opportunity to investigate and publish a fix.

## Personal project notice

`apm-overlay` is a personal open-source project. It is not a Microsoft product
and is not covered by Microsoft security support or Microsoft MSRC. References
to Microsoft- or GitHub-owned open-source projects identify public upstream
dependencies only.
